# Seoul Type — replacement visual system

Date: 2026-11-11  
Surface: GitHub Pages service and methodology page  
Modes: Operate (service), Read (methodology)

## Product mechanism

Korean source orthography is analysed, supported pronunciation is resolved, the result crosses an inspectable IPA boundary, and only then is it adapted to Ukrainian practical orthography. Uncertainty remains visible; a candidate is never presented as confirmed.

## Audience and use scene

Ukrainian-speaking readers and learners of Korean who repeatedly paste words or long passages, compare pronunciation, copy Ukrainian output, and sometimes inspect the IPA path. The service is a tool, not a marketing landing page.

## Replacement direction

Retire the previous jogakbo/cool-paper identity. Draw from contemporary Korean typographic publishing, independent poster design and screen-native editorial systems:
- real Hangul letterforms carry the visual identity;
- strong typographic scale and asymmetrical composition create character;
- the three-stage specimen uses ink / acid yellow / signal orange for source, IPA and Ukrainian;
- the input workbench is a focused dark working surface, followed by a bright answer surface;
- methodology is a long-form reading environment, not a dashboard.

No Taegeuk or flag motif, hanbok pattern, faux hanji grain, random Jamo, glassmorphism, AI-template gradients, floating metrics or repeated decorative labels.

## Seven concrete visual anchors

1. Hangul type specimen sheets — modular consonant/vowel construction and script-aware typography.
2. Seoul independent-culture posters — typographic scale, asymmetry and a restrained number of strong colour planes.
3. Korean book/newspaper page design — reading measure, spacing and the shift from vertical to horizontal Hangul composition.
4. Transit and wayfinding graphics — high-contrast navigation and immediate information hierarchy.
5. Contemporary exhibition identities — one flexible system across service and methodology surfaces.
6. Screen-native Hangul experiments — responsive letterforms and digital typography that remains language-first.
7. Phototypesetting and print-production artefacts — alignment, spacing and grid discipline without simulated paper effects.

The selected combination spans type, editorial publishing, public information graphics, exhibition identity and digital practice. It is not a literal reconstruction of one object or studio.

## Acceptance

- Korean input window first, answer window second at every viewport.
- Hero and specimen remain editorial compositions on desktop and reflow only at narrow widths.
- Ukrainian answer is visually dominant; supporting results remain grouped.
- Methodology has readable measure, structured contents, grouped grids and readable tables.
- No visible object-level caption strips, repeated eyebrow labels, fake metrics or decorative badge rows.
- Existing IDs, JavaScript hooks, input behavior, engine modes, IPA-first conversion, result status, clipboard recovery, spelling suggestions, trace disclosure and two-page CSP remain unchanged.
- No remote fonts, image CDNs, third-party runtime dependencies or conversion logic changes.
- Reduced motion, visible focus, touch targets, 320px reflow and overflow are checked.
- Node tests, production build, Verify, Tests, rendered review, Pages deployment and live smoke are run on the final commit.
