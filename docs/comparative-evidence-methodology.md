# Comparative evidence methodology

## Purpose

This document defines how the Korean → Ukrainian comparative master table assigns evidentiary status to Slavic comparator cells.

The central rule is simple:

> A missing or non-cellwise source is never converted into a fabricated one-to-one mapping.

The table is therefore a **comparative evidence matrix**, not a claim that every compared language has an official Korean-Jamo transcription standard.

## Evidence classes

| Class | Meaning |
|---|---|
| `exact_source_table` | The source itself publishes a corresponding Korean-to-target table or explicit row-level rule. |
| `proposal_exact_table_not_official` | The source publishes a row-level proposal, but explicitly does not establish an official national standard. |
| `system_level_not_cellwise_verified` | The source documents the history, principles, phonetic adaptation or general system, but the repository has not verified a row-by-row Jamo table. |
| `system_level_not_Jamo_table` | The source concerns Korean-to-language adaptation in actual names/toponyms rather than a Jamo inventory. |
| `reverse_adaptation_comparator` | The source is useful for receiving-language phonetics/orthography but works in the opposite direction or does not establish a Korean-to-target practical table. |
| `model` | A Ukrainian target generated by the project model rather than directly copied from a source. |
| `documented+model` | Source evidence establishes the Korean realization or receiving-language precedent, while the final Ukrainian target is a project-level synthesis. |

## Current comparator coverage

### Russian

Holodovich–Kontsevich is the strongest historical Cyrillic comparator. The published table gives row-level Korean consonant and vowel correspondences. It is therefore used as an exact-source comparator where the table directly supports the cell.

It is **not** the target authority for Ukrainian output.

### Ukrainian

Shchehel (2009) is the principal Ukrainian Korean-transcription precedent. It is treated differently from the foreign comparators because Ukrainian phonetics and Ukrainian orthography are the receiving-language target of this project.

The project nevertheless does not treat Shchehel as immutable: the repository separates documented precedent from model-derived decisions.

### Slovak

The documented Slovak proposal contains row-level basic-grapheme correspondences and is therefore retained as an exact-source comparator where the published table supports the cell. Its institutional status is kept distinct from a universally codified national standard.

### Bulgarian

Beneva et al. (2018) provides a practical Korean-to-Bulgarian system for names and words. It is retained as an exact-source practical comparator, while its Bulgarian-specific decisions are not imported into Ukrainian automatically.

### Serbian

Galjević (2023) is retained as a proposal-level exact table. The source itself is explicit about the proposal character, so the repository must never label it an established Serbian national standard.

### Czech

Stanjurová (2023) is a strong methodological and historical source for Czech Korean transcription. Until every row used in the master table has been checked against the thesis itself, Czech cells are intentionally not represented as exact one-to-one Jamo correspondences.

### Polish

Kim & Pietrow (2023) study Korean toponyms in Polish, transcription systems and phonic assimilation. This is excellent evidence for receiving-language adaptation, but it is not a complete Korean-Jamo→Polish grapheme table. The master table therefore does not fabricate one.

### Slovenian

The Slovenian literature is useful for Korean orthography and receiving-language adaptation, but the available source does not establish a reverse Korean-Jamo→Slovenian national practical table. It is therefore a reverse/adaptation comparator only.

## Ukrainian target hierarchy

Target selection follows:

1. Korean surface phonetic evidence.
2. Ukrainian Phonetic Inventory.
3. Ukrainian phonotactics and orthography.
4. Direct Ukrainian Koreanist precedent.
5. Cross-Slavic comparative evidence.
6. Foreign conventions only as supporting evidence.

A foreign Cyrillic convention cannot override a Ukrainian phonetic/orthographic constraint merely because it is historically established elsewhere.

## Aspiration

Korean aspiration remains visible in Korean phonology and IPA.

Primary Ukrainian practical output:

- ㅋ /kʰ/ → **к**
- ㅌ /tʰ/ → **т**
- ㅍ /pʰ/ → **п**
- ㅊ /tɕʰ/ → **ч**

Contrastive research output may expose aspiration separately, but it is not the default Ukrainian practical layer.

## Fortis

Korean fortisness remains explicit in the analytical layer. Primary Ukrainian practical output does not force initial doubling:

- ㄲ → к
- ㄸ → т
- ㅃ → п
- ㅆ → с
- ㅉ → ч

This is a deliberate receiving-language decision, not a claim that Korean fortisness is phonetically identical to Ukrainian plain consonants.

## Context-sensitive targets

The following are sequence-level decisions and must not be inferred from a bare Hangul block:

- contextual voicing;
- liaison/resyllabification;
- complex-coda simplification;
- nasal assimilation;
- liquid assimilation;
- tensification;
- ㅎ interactions;
- n-insertion;
- ㅢ realization;
- ㅅ/ㅆ palatalized environments.

## Publication rule

A row may be promoted from comparative research data into canonical correspondence only when:

1. Korean evidence is identified;
2. Ukrainian target rationale is explicit;
3. comparator provenance is explicit;
4. evidence class is assigned;
5. the target survives adversarial examples;
6. no unsupported national-standard claim remains.

The master table is consequently **auditable by design** rather than artificially complete.
