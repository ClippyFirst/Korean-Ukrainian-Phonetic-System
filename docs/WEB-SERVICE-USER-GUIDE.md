# Як користуватися сервісом

1. Відкрийте сторінку Сервіс.
2. Вставте корейський текст.
3. Натисніть Приклад для швидкої перевірки.
4. Прочитайте Український запис як основний практичний результат.
5. За потреби перегляньте IPA та Структуру Hangul.
6. Перевірте блок прозорості, щоб побачити застосовані контекстуальні правила.
7. Скопіюйте потрібний результат.

Сервіс не перекладає корейський текст за значенням.

Якщо з'являється попередження, система навмисно не вигадала відсутній або контекстно невизначений відповідник.
