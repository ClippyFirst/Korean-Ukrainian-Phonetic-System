# Web service user guide

Practical browser service for Korean → Ukrainian phonetic reading.

### М’яка морфологія

Прапорець **«М’яка морфологія (heuristic, низька впевненість)»** за замовчуванням
вимкнений. Увімкнення дозволяє рушію запропонувати читання для частих формальних
закінчень (частинки 이/을/에, сполучники 어/고, минулий час 았/었 тощо), коли
немає точного словникового запису.

Такі читання позначаються як `heuristic-low-confidence` і **не є** офіційною
сертифікацією NIKL. Для нормативної роботи залишайте прапорець вимкненим.
Деталі: `docs/SOFT-HEURISTIC-MORPHOLOGY-LAYER-2026-10-11.md`.

## Режими дослідницького рушія

- **Суворий:** використовує підтверджені правила й точні словникові форми; за відсутності доказів утримується від непідтвердженої вимови.
- **М’який:** успадковує колишній суперм’який шлях — обмежені морфологічні та ширші практичні евристики плюс IPA-резерв для невирішених переходів. Низьковпевнені фрагменти позначаються квадратними дужками.
- **Суперм’який:** графемний резерв. Кожен сучасний склад Hangul розкладається на початкову, голосну й кінцеву графеми; базовий IPA-кандидат формується без контекстних фонологічних припущень і проходить через спільний IPA → український адаптер.

Суперм’який режим максимізує технічне покриття, а не точність вимови. Він не застосовує асиміляцію, палаталізацію, liaison, напруження чи морфологічні винятки, якщо їх не містить точний словниковий запис. Невідомі вимовні умови не слід трактувати як встановлені. Для всіх режимів цільова українська форма походить від IPA, а не від прямої заміни корейських графем.
