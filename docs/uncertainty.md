# Uncertainty and competing analyses

The project uses explicit statuses:
- canonical;
- established;
- analysis-dependent;
- observed-variation;
- uncertain;
- unresolved.

## Vowels

The normative system contains 21 vowel symbols. The number of monophthongs and their surface realization varies with age and pronunciation model. In particular, ㅚ and ㅟ can participate in diphthongal realizations, and ㅐ/ㅔ merger is widespread in contemporary speech.

## Stops

The Korean three-way lenis/fortis/aspirated contrast is stable as a phonological category, but its acoustic cue weighting changes in contemporary Seoul speech. VOT/F0 is therefore not hard-coded as one universal narrow transcription.

## Rule ordering

Rule traces preserve order. Future analyses can compare alternative orderings without rewriting the underlying orthographic representation.
